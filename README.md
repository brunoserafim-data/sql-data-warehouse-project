# sql-data-warehouse-project
[![SQL](https://img.shields.io/badge/Language-SQL-blue.svg)](https://en.wikipedia.org/wiki/SQL)

### Objective
This portfolio project showcases an end-to-end data warehousing solution that turns raw data into actionable business intelligence. It implements industry-standard data engineering methodologies to deliver optimized, analytics-ready infrastructure.

### 📌 Building the Data Warehouse (Data Engineering) - Project Overview

This project involves:

* 🏗️ **Data Architecture**: Medallion Architecture implementation (Bronze / Silver / Gold).
* 🔄 **ETL Pipelines**: Automated extraction, transformation, and loading from source to warehouse.
* 🗄️ **Data Modeling**: Star schema development featuring optimized fact and dimension tables.
* 📈 **Business Intelligence**: SQL reporting and dashboard creation for actionable insights.

#### Specifications:
* **Data Sources:** Import ERP and CRM data from the provided flat files.
* **Data Quality:** Cleanse and resolve all quality issues prior to running analysis.
* **Integration:** Merge both sources into a unified, user-friendly analytical data model.
* **Scope:** Focus strictly on the latest dataset (historization is excluded).
* **Documentation:** Deliver clear model documentation for both business and analytics stakeholders.
